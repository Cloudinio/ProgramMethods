\doxysubsection{Detailed Description}
Класс красно-\/черного дерева для поиска объектов Player по ключу. В качестве ключа используется первое нечисловое поле объекта Player, а именно ФИО игрока. Каждый узел дерева хранит:\+ 


\begin{DoxyItemize}
\item строковый ключ;
\item список индексов элементов исходного массива с таким ключом;
\item цвет узла;
\item ссылки на потомков и родителя. Если в исходном массиве встречаются одинаковые ключи, они не создают новые узлы, а добавляются в вектор indices существующего узла. 
\end{DoxyItemize}
