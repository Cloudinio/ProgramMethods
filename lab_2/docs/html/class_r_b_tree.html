Detailed Description

Класс красно-черного дерева для поиска объектов Player по ключу. В качестве ключа используется первое нечисловое поле объекта Player, а именно ФИО игрока. Каждый узел дерева хранит:

  • строковый ключ;
  • список индексов элементов исходного массива с таким ключом;
  • цвет узла;
  • ссылки на потомков и родителя. Если в исходном массиве встречаются одинаковые ключи, они не создают новые узлы, а добавляются в вектор indices существующего узла.
