## Complexity: 
## Время
- В худшем случае $O(n^2)$
- В среднем и лучшем случаях `O(NlogN)` 
## Память
- В среднем `O(logN)`
- В худшем случае `O(N)`

```cpp
template<class T> void quickSortR(T* a, long N) {
	if (N <= 1) return;
	long i = 0, j = N-1;
	T p = a[ N>>1 ];
	
	do {
		while ( a[i] < p ) i++;
		while ( a[j] > p ) j--;
		
		if (i <= j) {
			swap(a[i], a[j]);
			i++;
			j--;
		}
	} while ( i<=j );

	if ( j > 0 ) quickSortR(a, j + 1);
	if ( N > i ) quickSortR(a + i, N - i);
}
```
Идея: берем рубежное значение последовательности, в левой части оставляем элементы, которые меньше `T p = a[ N>>1 ]`, а справа большие элементы. `i = 0, j = N-1` - индексы, указывающие на начало и конец массива.  Первые два `while` нужны для этой проверки. То есть сравниваем поэлементно и двигаем увеличивая индекс в случае успеха, в случае провала останавливаемся. Потом в `if` свапаем элементы, на которых остановились индексы. После свапа `i++, j--`, чтобы сдвинуть индексы. В последних двух `if` мы рекурсивно идем в последовательность, элементы которой меньше рубежного элемента, и в последовательность, элементы которой больше рубежного элемента.
