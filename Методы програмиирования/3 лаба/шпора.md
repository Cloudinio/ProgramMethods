**Коэффициент вариации** — это показатель, который показывает, насколько большой разброс у данных **относительно среднего значения**.

Стандартное отклонение показывает абсолютный разброс.  
А коэффициент вариации показывает **относительный разброс**.

**Стандартное отклонение** — это число, которое показывает, насколько сильно значения в выборке в среднем отклоняются от среднего значения.

static_cast - безопасное на уровне компиляции приведение типа. компилятор проверяет, что такое преобразование в принципе допустимо, но не проверяет реальный тип объекта во время выполнения. 

dinamic_cast - приведение типа с проверкой во время выполнения. С указателями `dynamic_cast` возвращает `nullptr`, если приведение невозможно. 
```cpp
class Animal {
public:
    virtual ~Animal() {}
};

class Dog : public Animal {
public:
    void bark() {}
};

class Cat : public Animal {
public:
    void meow() {}
};

int main() {
    Cat cat;
    Animal* a = &cat; // создали переменную `a`, которая имеет тип `Animal*`, то есть “указатель на `Animal`”, и записали в неё адрес объекта `cat`.

    Dog* d = dynamic_cast<Dog*>(a);

    if (d != nullptr) {
        d->bark();
    } else {
        cout << "Это не собака" << endl;
    }
}
```
Ситуация: создали класс `Animal`, от которого наследуются два класса `Dog` и `Cat`. Создаю объект кошка и потом делаю переменную `a`, которая является указателем на `Animal`, и записали туда адрес кошки. Потом через `dinamic_cast` привожу переменную `a` к собаке и получаю переменную `d`. И если я вызову метод собаки, то `d` будет `nullptr`, так как на самом деле идет указание на кошку. Если бы я сделал `static_cast`, то было бы неопределенное поведение программы.

`static_cast` приводит типы на этапе компиляции, а `dynamic_cast` на этапе исполнения (`runtime`). 
`static_cast` выполняет приведение, которое проверяется компилятором на этапе компиляции: компилятор проверяет, допустимо ли такое преобразование между типами. Но `static_cast` не проверяет реальный тип объекта во время выполнения.  
`dynamic_cast` выполняет проверку во время выполнения (`runtime`) и определяет, действительно ли объект можно привести к нужному типу.
