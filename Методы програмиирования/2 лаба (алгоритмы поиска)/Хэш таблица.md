Хеш-таблица (hash table) — это специальная структура данных для хранения пар ключей и их значений. По сути это ассоциативный массив, в котором ключ представлен в виде хеш-функции.
Главное свойство хэш-таблиц — все три операции вставка, поиск и удаление в среднем выполняются за время O(1), среднее время поиска по ней также равно O(1) и O(n) в худшем случае.

## Complexity: `O(1)`, `O(N)` в худшем случае при поиске.

## Entry

	vector<int> indices;
	Entry(const string& k, int index) : key(k), indices{index} {}

## HashString
```cpp
unsigned long long hashString(const string& s) const {
	const unsigned long long P = 53;
	unsigned long long hash = 0;
	unsigned long long p_pow = 1;
	for (char c : s) {
		hash += (unsigned long long)(unsigned char)c * p_pow;
		p_pow *= P;
	}
	return hash;
}
```
Функция расчета хеша. Используется дефолт формула ![[Pasted image 20260510010734.png]]
Выбрал `P` = 53, так как в ФИО могут быть большие буквы, маленькие буквы, пробелы, русские символы, знаки и так далее.
`(unsigned long long)(unsigned char)c` надо, так как `char` может быть знаковым, а потом переделываем в `long long`, чтобы умножить на `p_pow`(очень большое число).

## Insert
```cpp
void insert(const Player& player, int index) {
	string key = getKey(player);
	size_t pos = indexForKey(key);
	if (!table[pos].empty()) {
		bool sameKeyExists = false;
		for (auto& entry : table[pos]) {
			if (entry.key == key) {
				entry.indices.push_back(index);
				sameKeyExists = true;
				break;
			}
		}
		if (sameKeyExists) return;
		collisions++;
	}
	table[pos].emplace_back(key, index);
}
```
Функция вставки в таблицу. Суть: понимаем в какой корзинке будет объект, дальше проверяем не пуста ли корзинка. Если пуста, значит просто добавляем туда через emplace_back(то есть как push_back, но не создается копия, а вызывается конструктор `Entry`). Если не пуста, значит это или коллизия, или уже есть объект с таким же ключом. 
Если объект с таким же ключом, то просто добавляю в вектор индекс, если коллизия, то увеличиваю счетчик коллизий и добавляем новый объект в корзинку.
