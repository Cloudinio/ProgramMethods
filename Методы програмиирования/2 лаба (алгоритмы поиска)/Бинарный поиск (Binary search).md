## Complexity: `O(logN)`

!!! **Важно**, чтобы массив был отсортирован

Суть: на каждом шаге мы ищем середину рассматриваемого отрезка по формуле:
```
mid = (left - right) / 2
```
В случае если искомый элемент меньше элемента с индексом `mid`, правая граница рассматриваемого отрезка перемещается на позицию `mid`, иначе — левая граница. Если искомый элемент равен элементу с индексом `mid`, необходимо продолжить поиск среди соседних элементов слева и справа, пока не встретятся другие элементы. Таким образом, результатом являются левая и правая границы искомых элементов в массиве. Если остался только один элемент, левая и правая границы равны.
```C++
template<class T> int binary_search(T a[], int start, int end, const T& key) {
    if(start > end)
        return -1;
    const int middle = start + ((end - start) / 2);
    if(a[middle] == key)
        return middle;
    else if(a[middle] > key)
        return binary_search(a, start, middle - 1, key);
    return binary_search(a, middle + 1, end, key);
}
```
