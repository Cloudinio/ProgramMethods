

# Методы программирования

Репозиторий с лабораторными работами по дисциплине **«Методы программирования»**.

В рамках работ были реализованы алгоритмы обработки данных, структуры данных, поиск, хеширование, генераторы псевдослучайных чисел, статистические проверки и документация Doxygen.

## Лабораторная работа №1

В первой лабораторной работе была выполнена базовая работа с пользовательскими структурами данных и алгоритмами поиска.

Основные элементы работы:

- описание класса для хранения данных об объектах;
- реализация чтения и обработки данных;
- использование линейного поиска;
- сравнение объектов через перегрузку операторов;
- подготовка к дальнейшему использованию данных в следующих лабораторных работах.

Работа позволила закрепить базовые принципы работы с классами, массивами/векторами, файлами и алгоритмами поиска в C++.

## Лабораторная работа №2

Во второй лабораторной работе была реализована структура данных **хеш-таблица**.

Основные элементы работы:

- реализация хеш-таблицы методом цепочек;
- хранение ключей и индексов элементов исходного массива;
- обработка коллизий;
- анализ количества коллизий при разных размерах выборки;
- построение графиков зависимости коллизий от размера выборки.

В работе была рассмотрена важная проблема хеширования: даже при достаточно большом размере таблицы коллизии всё равно возможны, особенно при росте объёма данных и неидеальном распределении ключей.

## Лабораторная работа №3

В третьей лабораторной работе были реализованы и исследованы генераторы псевдослучайных чисел.

Были реализованы следующие генераторы:

- `ModifiedMiddleProductXor` — модифицированный метод серединных произведений с xorshift-перемешиванием;
- `ModifiedLCGPermuted` — модифицированный линейный конгруэнтный генератор с дополнительным перемешиванием;
- `XorShift32Salt` — генератор на основе xorshift32 с добавочной солью;
- `std::mt19937` — стандартный генератор Mersenne Twister для сравнения скорости.

Для проверки качества генераторов были использованы статистические характеристики и тесты:

- среднее значение;
- стандартное отклонение;
- коэффициент вариации;
- критерий хи-квадрат для проверки равномерности распределения;
- битовый frequency test;
- runs test;
- serial 2-bit test;
- poker test для 4-битных блоков;
- overlapping permutations test;
- birthday spacings test.

Также был выполнен замер времени генерации для разных размеров выборки и построен график зависимости времени генерации от размера выборки.

## Документация

Для лабораторных работ используется документация в формате **Doxygen**.

В код добавлены Doxygen-комментарии к классам, структурам и функциям. Это позволяет автоматически генерировать HTML-документацию по исходному коду.

Пример запуска генерации документации:

```bash
doxygen Doxyfile
```

После генерации документацию можно открыть через файл:

```text
docs/html/index.html
```
